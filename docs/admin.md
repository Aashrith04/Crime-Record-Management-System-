# CRMS System Administrator Manual

## 1. System Roles & Access Matrix
CRMS enforces 6 granular system roles:
1. **Super Admin**: Full administrative control across system settings, user creation, role assignment, and audit log inspection.
2. **Commissioner**: Executive dashboard view, high-level analytical reports, and cross-station metrics.
3. **Station Admin**: Police station administration, officer assignments, and FIR approval.
4. **Police Officer**: Case entry, investigation timeline entries, and evidence uploads.
5. **Investigator**: Forensic analysis, entity resolution feedback, and cross-case linking.
6. **Data Entry**: Basic record entry for crimes and FIR forms.
